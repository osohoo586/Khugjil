# Mac-ыг сервер болгох (khugjil.usukh.shop)

Жинхэнэ сервер (VPS) авах хүртэл системийг энэ Mac дээр ажиллуулж, `usukh.shop` домэйнээр
нийтэд гаргах заавар.

| Юу | Хаяг |
|---|---|
| Админ хэсэг | https://khugjil.usukh.shop |
| Кассын дэлгэц | https://khugjil-kass.usukh.shop |
| Банкны имэйл хүлээн авах | `<нууц хаяг>@in.khugjil.usukh.shop` |

**Хэрхэн ажилладаг вэ:** Cloudflare Tunnel нь Mac-аас Cloudflare руу **гадагш** холболт үүсгэдэг.
Иймд гэрийн рүүтерт порт нээх шаардлагагүй, Mac дээр гаднаас шууд хандах порт нээгдэхгүй. Банкны
имэйл ингэж ирнэ: Gmail → Cloudflare Email Routing → Cloudflare Worker (`cf-worker/`) → туннель → Mac.

**Хязгаарлалт:**

- Mac унтах эсвэл унтрах үед мэдэгдэл ирэхгүй. Ажлын цагаар Mac-ыг унтуулахгүй байхын тулд
  терминалд `caffeinate -dimsu` ажиллуулна, эсвэл **System Settings → Battery/Energy** хэсгээс тохируулна.
- Энэ горимд холболтын HTTPS-ийг Cloudflare хариуцдаг тул урсгал Cloudflare-аар дамжина.
  Жинхэнэ сервер дээр гаргахад энэ шаардлагагүй болно (README → Deployment).
- Энэ горим нь туршилтын демо орчноос (`scripts/dev-up.sh`) **тусдаа**: өөрийн өгөгдлийн сан,
  өөрийн нууц түлхүүртэй. Түлхүүрүүд `.dev/public/` хавтаст үүсэх бөгөөд repo-д орохгүй, хэнд ч
  харагдахгүй.

## 1. Голомт дээр имэйл мэдэгдэл асаах (нэг удаа)

egolomt.mn → **Харилцах данс** → **Изи инфо** → суваг: **И-мэйл** → Gmail хаягаа оруулна.
Апп-аар бол **Үйлчилгээ** → **Easy info**.

## 2. Банкны 3 утга

Голомтоос ирсэн орлогын имэйлийг Gmail-ээр нээгээд **⋮ → Show original** дарна. Дээд хэсгээс
**From**, **Subject**, **DKIM: 'PASS' with domain …** гэсэн гурван утгыг аваад Claude-д хэлбэл
`.dev/public/bank.sh` файлыг бөглөж өгнө. Аль нь ч нууц мэдээлэл биш.

## 3. Асаах

```sh
./scripts/public-deploy.sh   # эхний удаа болон шинэ хувилбар гаргах бүрт
./scripts/public-up.sh       # Mac дахин асаасны дараа (одоо байгаа хувилбарыг асаана)
```

- Сайт энэ хавтаснаас **шууд биш**, `.dev/releases/<commit>` гэсэн тусдаа хуулбараас ажиллана.
  Код засах, кассын хуудсыг build хийх, branch солих нь ажиллаж буй сайтад нөлөөлөхгүй.
- `public-deploy.sh` нь зөвхөн **commit хийсэн** кодыг гаргана: шинэ хувилбарыг хуучин нь
  ажиллаж байх зуур бэлдээд, сервер зогсоож, өгөгдлийн сангийн миграцийг хийгээд, дараа нь шинэ
  кодыг асаана. Унаад дахин асах үед ч мөн тэр хувилбар ачаалагдана.
- Буцаах: `./scripts/public-deploy.sh <өмнөх commit>`. Сүүлийн хэдэн хувилбар хадгалагдана.

- Эхний удаад өгөгдлийн сан, нууц түлхүүрүүд, таны дэлгүүр болон Cloudflare туннель үүснэ.
  Туннель үүсэхэд `khugjil.usukh.shop`, `khugjil-kass.usukh.shop` гэсэн DNS бичлэгүүд Cloudflare
  дээр **автоматаар** нэмэгдэнэ.
- Скрипт админ хэсгийн хаяг болон **эзэмшигчийн урилгын холбоосыг** хэвлэнэ. Холбоосыг нээж
  нэвтрэх нэр, нууц үгээ тохируулаад, утасны апп-аар хоёр шаттай баталгаажуулалтаа идэвхжүүлнэ.

Зогсоох: `./scripts/public-down.sh`. Өгөгдөл хадгалагдана, дараа нь дахин `public-up.sh`
ажиллуулахад үргэлжилнэ. `dev-down.sh --wipe` нь демо stack-ийн файлыг л устгана, энэ сайтын
түлхүүр (`.dev/public`) болон хувилбаруудад (`.dev/releases`) хүрэхгүй.

**Удаан хугацаагаар зогсоох бол Worker-ийг түр зогсооно.** Сервер унтарсан үед Gmail банкны
имэйл бүрийг дамжуулж чадахгүй тул дахин оролдож, эцэст нь танд «хүргэгдсэнгүй» гэсэн мэдэгдэл
илгээдэг. Түр зогсоосон Worker имэйлийг хүлээн аваад устгадаг тул ийм мэдэгдэл ирэхгүй. Эх имэйл
Gmail-д хэвээр үлдэнэ.

```sh
cd cf-worker
# Түр зогсоох
npx wrangler@4.154.0 deploy --var KHJ_HOOK_URL:https://khugjil-kass.usukh.shop/hooks/cf --var KHJ_PAUSED:1
# Дахин асаах (public-up.sh-ийн дараа)
npx wrangler@4.154.0 deploy --var KHJ_HOOK_URL:https://khugjil-kass.usukh.shop/hooks/cf --var KHJ_PAUSED:0
```

Түр зогсоосон үед касс руу мэдэгдэл огт очихгүй. Серверээ асаасны дараа Worker-ийг заавал дахин
асаана уу.

## 4. Банкны имэйлийг системд холбох (нэг удаа)

**4.1. Cloudflare Email Routing.** dash.cloudflare.com → **usukh.shop** → **Email** →
**Email Routing**. Хэрэв идэвхжээгүй бол идэвхжүүлнэ. Дараа нь **Settings → Subdomains** хэсэгт
`in.khugjil.usukh.shop`-ийг нэмнэ. Cloudflare шаардлагатай MX бичлэгүүдийг өөрөө нэмнэ.

**4.2. Worker суулгах.** Терминалд дараахыг ажиллуулна. Нууц түлхүүрийг файлаас нь шууд
дамжуулдаг тул хаана ч хуулж буулгах шаардлагагүй.

```sh
cd cf-worker
npx wrangler@4.154.0 login
npx wrangler@4.154.0 deploy --var KHJ_HOOK_URL:https://khugjil-kass.usukh.shop/hooks/cf
cat ../.dev/public/cf-ingest-secret | npx wrangler@4.154.0 secret put KHJ_CF_INGEST_SECRET
```

**4.3. Чиглүүлэх дүрэм.** Email Routing → **Routing rules** → `in.khugjil.usukh.shop`-ийн
**Catch-all** → **Send to a Worker** → `khugjil-email`.

**4.4. Gmail дамжуулалт.**

1. Админ хэсгийн **Тохиргоо → Банкны имэйл** хуудаснаас хүлээн авах хаягаа хуулна. Хэд хэдэн Gmail-ээс
   дамжуулах бол Gmail бүрт **Хаяг нэмэх** товчоор тусдаа хаяг үүсгэнэ.
2. Gmail → **Тохиргоо → Дамжуулалт ба POP/IMAP → Дамжуулах хаяг нэмэх** → хаягаа оруулна.
3. Gmail баталгаажуулах код илгээнэ. Код хэдэн секундын дотор **Банкны имэйл** хуудсанд
   гарна. Тэр кодыг Gmail-д оруулна.
4. Gmail → **Шүүлтүүр үүсгэх** → **Хэнээс** талбарт Голомтын илгээгч хаягийг бичнэ →
   **Дараах хаяг руу дамжуулах** → хүлээн авах хаягаа сонгоно.

Үүний дараа Голомтоос орлогын имэйл ирэх бүрт хэдхэн секундын дотор касс дээр мэдэгдэл гарна.
Имэйл ирсэн эсэхийг **Банкны имэйл** хуудасны «Сүүлд ирсэн имэйл» хүснэгтээс харна.

## 5. Кассын компьютер

1. Админ хэсэгт:
   - **Тохиргоо → Дансууд** хуудсанд Голомтын дансаа бүтэн дугаараар нь нэмнэ. Систем имэйл дээрх
     далдлагдсан дугаартай тулгана. Эсвэл **Тохиргоо → Ерөнхий** хуудсанд «Бүртгэлгүй данс руу орсон орлогыг
     хүлээн авч, дансыг автоматаар нэмэх»-ийг асаавал орлого ирсэн данс имэйл дээрх хэлбэрээрээ («Данс 160…04»)
     өөрөө нэмэгдэж, бүх идэвхтэй бүлэгт холбогдоно.
   - **Тохиргоо → Бүлгүүд** хуудсанд бүлэг үүсгээд дансаа холбоно.
   - **Төхөөрөмж** хуудаснаас код үүсгэнэ.
2. Кассын компьютерт https://khugjil-kass.usukh.shop/pair хаягийг нээж кодыг оруулна. Ингэснээр
   нэвтрэлт дуусна: ээлж, ПИН код шаардлагагүй, сүүлийн гүйлгээнүүд шууд харагдана. Төхөөрөмжийн
   бүлэгт эзэмшигч (та) нэмэгдсэн байх ёстой.
3. «Дуу идэвхгүй — дарж идэвхжүүлнэ үү» мөрийг нэг удаа дарж дуут дохио болон хөтчийн мэдэгдлийг
   зөвшөөрнө.

Кассчин бүр ПИН кодоор ээлж эхлүүлдэг байхыг хүсвэл **Тохиргоо → Ээлж** хэсэгт «Кассчин ПИН
кодоор ээлж эхлүүлнэ»-г сонгоод, **Хэрэглэгчид** хуудаснаас кассчин урина.

## Тасралтгүй ажиллуулах

- **Цэнэглэгчид залгаатай, таг нь онгорхой байлгана.** `public-up.sh` Mac-ийг идэвхгүй үед
  унтуулахгүй (`caffeinate`). Гэхдээ таг хаавал эсвэл батарей дуусвал Mac унтаж, систем бүхэлдээ
  зогсоно. Тэр хооронд ирсэн гүйлгээг Gmail хэдэн цаг, хоногийн дараа дахин илгээнэ.
- **Унасан процесс өөрөө асна.** API, worker, туннель гэнэт зогсвол 3 секундын дотор дахин асна
  (`.dev/public/*.log`-д «restarting» гэж бичигдэнэ). Mac дахин ачаалсны (restart) дараа
  `./scripts/public-up.sh`-ийг гараар ажиллуулна. Docker Desktop нэвтрэхэд автоматаар асдаг
  байх ёстой.
- **Хоцорч ирсэн гүйлгээ.** Банкны цагаас 10 минутаас хойш серверт хүрсэн гүйлгээ касс дээр дуу,
  мэдэгдэлгүйгээр зөвхөн жагсаалтад банкны цагийн дарааллаар орно. Ингэснээр хуучин төлбөрийг
  кассчин одоо ирсэн гэж андуурахгүй.
- **Админ ба касс.** Админы **Тойм** хуудас өнөөдрийн дүн болон сүүлийн 5 орлогыг 10 секунд тутам
  шинэчилнэ. Бүлэг, данс, тохиргоо өөрчлөхөд нээлттэй касс хуудас шууд шинэчлэгдэнэ. Касс 30
  секунд тутам алдагдсан гүйлгээ байгаа эсэхийг давхар шалгана.

## Асуудал гарвал

- **Хуудас нээгдэхгүй бол:** `.dev/public/tunnel.log` болон `.dev/public/api.log`-ийг шалгана.
  Mac сэрүүн байгаа эсэх, `public-up.sh` ажиллаж байгаа эсэхийг шалгана.
- **Имэйл ирэхгүй бол:** **Банкны имэйл** хуудасны хүснэгтийг шалгана.
  - Мөр огт гарахгүй бол Cloudflare Email Routing эсвэл Worker-т асуудал байна. Worker түр
    зогссон (`KHJ_PAUSED:1`) эсэхийг шалгана.
  - «Татгалзсан — …» гэж гарвал шалтгааныг нь Claude-д хэлээрэй.
