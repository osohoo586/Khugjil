# Mac-ыг сервер болгох (khugjil.usukh.shop)

Жинхэнэ сервер (VPS) авах хүртэл системийг энэ Mac дээр ажиллуулж, `usukh.shop` домэйнээр
нийтэд гаргах заавар.

| Юу | Хаяг |
|---|---|
| Админ хэсэг | https://khugjil.usukh.shop |
| Кассын дэлгэц | https://khugjil-kass.usukh.shop |
| Банкны имэйл хүлээн авах | `<нууц хаяг>@in.khugjil.usukh.shop` |

**Хэрхэн ажилладаг вэ:** Cloudflare Tunnel нь Mac-аас Cloudflare руу **гадагш** холболт үүсгэдэг.
Иймд гэрийн рүүтерт порт нээх шаардлагагүй, Mac дээр гаднаас шууд хандах порт нээгдэхгүй. Банкны
имэйл ингэж ирнэ: Gmail → Cloudflare Email Routing → Cloudflare Worker (`cf-worker/`) → туннель → Mac.

**Хязгаарлалт:**

- Mac унтах эсвэл унтрах үед мэдэгдэл ирэхгүй. Ажлын цагаар Mac-ыг унтуулахгүй байхын тулд
  терминалд `caffeinate -dimsu` ажиллуулна, эсвэл **System Settings → Battery/Energy** хэсгээс тохируулна.
- Энэ горимд холболтын HTTPS-ийг Cloudflare хариуцдаг тул урсгал Cloudflare-аар дамжина.
  Жинхэнэ сервер дээр гаргахад энэ шаардлагагүй болно (README → Deployment).
- Энэ горим нь туршилтын демо орчноос (`scripts/dev-up.sh`) **тусдаа**: өөрийн өгөгдлийн сан,
  өөрийн нууц түлхүүртэй. Түлхүүрүүд `.dev/public/` хавтаст үүсэх бөгөөд repo-д орохгүй, хэнд ч
  харагдахгүй.

## 1. Голомт дээр имэйл мэдэгдэл асаах (нэг удаа)

egolomt.mn → **Харилцах данс** → **Изи инфо** → суваг: **И-мэйл** → Gmail хаягаа оруулна.
Апп-аар бол **Үйлчилгээ** → **Easy info**.

## 2. Банкны 3 утга

Голомтоос ирсэн орлогын имэйлийг Gmail-ээр нээгээд **⋮ → Show original** дарна. Дээд хэсгээс
**From**, **Subject**, **DKIM: 'PASS' with domain …** гэсэн гурван утгыг аваад Claude-д хэлбэл
`.dev/public/bank.sh` файлыг бөглөж өгнө. Аль нь ч нууц мэдээлэл биш.

## 3. Асаах

```sh
./scripts/public-up.sh
```

- Эхний удаад өгөгдлийн сан, нууц түлхүүрүүд, таны дэлгүүр болон Cloudflare туннель үүснэ.
  Туннель үүсэхэд `khugjil.usukh.shop`, `khugjil-kass.usukh.shop` гэсэн DNS бичлэгүүд Cloudflare
  дээр **автоматаар** нэмэгдэнэ.
- Скрипт админ хэсгийн хаяг болон **эзэмшигчийн урилгын холбоосыг** хэвлэнэ. Холбоосыг нээж
  нэвтрэх нэр, нууц үгээ тохируулаад, утасны апп-аар хоёр шаттай баталгаажуулалтаа идэвхжүүлнэ.

Зогсоох: `./scripts/public-down.sh`. Өгөгдөл хадгалагдана, дараа нь дахин `public-up.sh`
ажиллуулахад үргэлжилнэ.

## 4. Банкны имэйлийг системд холбох (нэг удаа)

**4.1. Cloudflare Email Routing.** dash.cloudflare.com → **usukh.shop** → **Email** →
**Email Routing**. Хэрэв идэвхжээгүй бол идэвхжүүлнэ. Дараа нь **Settings → Subdomains** хэсэгт
`in.khugjil.usukh.shop`-ийг нэмнэ. Cloudflare шаардлагатай MX бичлэгүүдийг өөрөө нэмнэ.

**4.2. Worker суулгах.** Терминалд дараахыг ажиллуулна. Нууц түлхүүрийг файлаас нь шууд
дамжуулдаг тул хаана ч хуулж буулгах шаардлагагүй.

```sh
cd cf-worker
npx wrangler@4.154.0 login
npx wrangler@4.154.0 deploy --var KHJ_HOOK_URL:https://khugjil-kass.usukh.shop/hooks/cf
cat ../.dev/public/cf-ingest-secret | npx wrangler@4.154.0 secret put KHJ_CF_INGEST_SECRET
```

**4.3. Чиглүүлэх дүрэм.** Email Routing → **Routing rules** → `in.khugjil.usukh.shop`-ийн
**Catch-all** → **Send to a Worker** → `khugjil-email`.

**4.4. Gmail дамжуулалт.**

1. Админ хэсгийн **Имэйл холболт** хуудаснаас хүлээн авах хаягаа хуулна.
2. Gmail → **Тохиргоо → Дамжуулалт ба POP/IMAP → Дамжуулах хаяг нэмэх** → хаягаа оруулна.
3. Gmail баталгаажуулах код илгээнэ. Код хэдэн секундын дотор **Имэйл холболт** хуудсанд
   гарна. Тэр кодыг Gmail-д оруулна.
4. Gmail → **Шүүлтүүр үүсгэх** → **Хэнээс** талбарт Голомтын илгээгч хаягийг бичнэ →
   **Дараах хаяг руу дамжуулах** → хүлээн авах хаягаа сонгоно.

Үүний дараа Голомтоос орлогын имэйл ирэх бүрт хэдхэн секундын дотор касс дээр мэдэгдэл гарна.
Имэйл ирсэн эсэхийг **Имэйл холболт** хуудасны «Сүүлд ирсэн имэйлүүд» хүснэгтээс харна.

## 5. Кассын компьютер

1. Админ хэсэгт:
   - **Дансууд** хуудсанд Голомтын дансаа бүтэн дугаараар нь нэмнэ. Систем имэйл дээрх
     далдлагдсан дугаартай тулгана.
   - **Бүлгүүд** хуудсанд бүлэг үүсгээд дансаа холбоно.
   - **Хэрэглэгчид** хуудаснаас кассчин урина.
   - **Төхөөрөмжүүд** хуудаснаас код үүсгэнэ.
2. Кассын компьютерт https://khugjil-kass.usukh.shop/pair хаягийг нээж кодыг оруулна.
3. Кассчин нэрээ сонгож ПИН кодоор **Ээлж эхлүүлэх** дарна.
